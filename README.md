# IELTSophy 

An adaptive web trainer for IELTS Reading preparation.

## About

IELTSophy is an educational web service that helps students prepare for the IELTS Reading section. The system adapts to the user's level (B1–C2), tracks progress, and provides personalized analytics.

## Features

- **Adaptive difficulty** - level changes based on test results
- **Texts by level and topic** - Science, History, Ecology, Business, Society
- **Answer checking** - instant feedback with mistakes list
- **User profile** - statistics, streak, IELTS band forecast, achievements
- **Vocabulary** - save and review words
- **Analytics** - weak areas, test history, progress charts
- **Preparation videos** - curated YouTube content
- **Light/Dark theme** - with saved preference
- **Authentication** - Google OAuth 2.0
